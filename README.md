# PAI_final_ueyamaOUJ
【Physical AI講座2026 応用編1｜最終課題】

東京大学 松尾・岩澤研究室が開講する「Physical AI講座2026 応用編1」は、AIとロボットの融合領域におけるシステム構築を実践的に学び、AIロボットの開発・運用に必要な知識と技術の習得を目指す講座です。
本講座では、AIロボット開発におけるデータ収集・モデル学習・検証のサイクルを支えるMLOps・RobOpsをはじめ、コンピュータアーキテクチャ、通信技術、Docker、ROS2など、ロボットシステムの開発に必要な基盤技術について体系的に学びました。
本動画は、講座で習得した知識や技術を活用し、学習成果として制作した最終課題の成果物です。
